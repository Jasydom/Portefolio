À propos

Des maths à l'IA appliquée

Je m'appelle Adrien Montaigne, ingénieur spécialisé en Mathématiques Appliquées, passionné par les domaines de la Data Science et de l'Intelligence Artificielle. Fort de plusieurs expériences en tant que Data Scientist et développeur, j'ai développé une solide expertise en Machine Learning, NLP (Natural Language Processing) et analyse de données massives.

Lors de mes missions chez BNP Paribas, Equanimity et Carrefour Banque, j'ai pu mettre en œuvre des modèles prédictifs avancés, concevoir des solutions de traitement du langage naturel, et optimiser des flux de données pour des environnements complexes. Mon parcours académique à CY Tech et un semestre d'échange à Anglia Ruskin University ont renforcé mes compétences en statistiques et en programmation, me permettant de mener à bien des projets variés, de l'analyse de sentiment à la prédiction de consommations de stockage.

01Vision par ordinateur

Classification d'images réelles vs générées par IA

Ce projet vise à développer un modèle capable de distinguer les images réelles des images générées par IA. Dans le cadre de ce projet, j'ai conçu un modèle CNN (Convolutional Neural Network) à partir de zéro et effectué une optimisation des hyperparamètres. En complément, j'ai également développé un second modèle basé sur le transfert d'apprentissage à partir d'une architecture ResNet.

  • CNN
  • ResNet
  • Transfer learning
Code source — Classification d'images réelles vs générées par IA
02NLP

Analyse de sentiment sur les vaccins

Ce projet vise à analyser le sentiment public à propos de différents vaccins en utilisant divers paramètres tels que les hashtags, la popularité, le statut de vérification des utilisateurs, et l'engagement des tweets. L'objectif est d'identifier les caractéristiques des principaux utilisateurs et de mesurer le sentiment général de l'opinion publique sur chaque vaccin.

  • Analyse de sentiment
  • Twitter
Code source — Analyse de sentiment sur les vaccins
03Vision par ordinateur

Reconnaissance de sports à partir de vidéos

L'objectif de ce projet est de reconnaître automatiquement le sport pratiqué dans une vidéo en se basant uniquement sur les mouvements des participants. Pour ce projet, nous avons utilisé des CNN pour extraire les caractéristiques spatiales des mouvements, suivis de RNN pour capturer les dynamiques temporelles et ainsi reconnaître le sport pratiqué dans la vidéo.

  • CNN
  • RNN
  • Vidéo
Code source — Reconnaissance de sports à partir de vidéos

Prédiction du diabète

Ce projet utilise des techniques avancées de machine learning, telles que l'apprentissage par ensemble et des algorithmes variés comme Random Forest, Régression Logistique, et SVM pour prédire le diabète. En explorant différentes métriques de performance et en testant plusieurs modèles, l'objectif est d'obtenir une prédiction optimale et de comprendre les facteurs qui influencent le risque de diabète.

  • Random Forest

  • SVM

Extraction d'EPS

Ce projet vise à extraire les données de Bénéfice Par Action (EPS) de rapports financiers en HTML à l'aide de techniques de web scraping et de regex. En utilisant BeautifulSoup pour le parsing HTML et une série de modèles regex pour identifier les valeurs EPS, l'objectif est de développer une méthode fiable pour extraire ces informations financières.
